Moonshine Streaming Tiny Tagalog frontend in ORT format, provided for
compatibility with Moonshine WASM 0.1.6. The original model is by Moonshine AI.
https://huggingface.co/moonshine-ai/moonshine-streaming-tiny-tl

Source frontend graph (MIT), converted from ONNX to ORT without changing weights.
https://huggingface.co/Masterx/moonshine-streaming-tiny-tl-ONNX

The remaining model files are loaded from Moonshine AI's model CDN.
